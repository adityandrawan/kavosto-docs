Selamat datang di panduan Kavosto. Temukan langkah untuk menyiapkan gym, melayani member, dan memantau usaha Anda dalam satu tempat.

## Baru menggunakan Kavosto?

Mulai dari [panduan persiapan gym](/id/getting-started). Anda akan dipandu melengkapi profil, membuat paket membership, mengatur pembayaran, dan memberikan akses kepada tim.

Jika gym sudah siap, langsung pilih panduan sesuai pekerjaan yang ingin Anda selesaikan. Tidak perlu membaca semuanya dari awal.

## Temukan panduan Anda

| Kebutuhan | Buka panduan |
| --- | --- |
| Mendaftarkan pelanggan gym | [Member](/id/operations/members) |
| Menjual atau memperpanjang keanggotaan | [Membership](/id/operations/memberships) |
| Mencatat kedatangan dan kepulangan | [Check-in](/id/operations/check-in) |
| Menerima pembayaran dan mencetak struk | [Kasir](/id/operations/point-of-sale) |
| Mengatur latihan dan peserta kelas | [Kelas dan personal trainer](/id/operations/classes-and-personal-training) |
| Membeli barang dari supplier | [Pembelian barang](/id/purchasing/purchase-orders) |
| Mencatat pembayaran tagihan supplier | [Tagihan supplier](/id/purchasing/supplier-invoices) |
| Memeriksa atau menyesuaikan stok | [Persediaan](/id/products-inventory/inventory) |
| Mengirim pesan otomatis ke member | [Pesan Member](/id/administration/member-messages) |
| Meninjau hasil operasional | [Laporan dan pengeluaran](/id/finance/reports-and-expenses) |

## Kenali akses akun Anda

Nama menu dalam panduan mengikuti aplikasi. Menu dan data yang terlihat dapat berbeda sesuai paket langganan gym, peran, dan akses cabang Anda.

Sebelum mulai bekerja, pastikan cabang yang dipilih sudah sesuai. Jika menu yang Anda butuhkan tidak tersedia, minta pemilik atau admin gym memeriksa akses akun Anda.

## Butuh bantuan?

Gunakan pencarian untuk menemukan topik tertentu, atau buka [Bantuan dan kendala umum](/id/help) untuk langkah pemeriksaan saat menemui masalah.
