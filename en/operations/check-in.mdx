Record member arrivals and validate their access through **Check-in**. Make sure the selected branch matches the location of the visit.

## Record an arrival

1. Check the active branch.
2. If entry and exit mode is enabled, select **Masuk**.
3. Scan the member number with a scanner, enter it manually, or use the camera to read a QR code.
4. Wait for validation and check the member's identity in the result.
5. Make sure the visit appears in the history.

<Tip>
  The QR code or barcode must contain the member number. If the camera is unavailable, use **Cari member manual** to continue serving members.
</Tip>

## Find a member manually

Choose **Cari member manual**, search by name or member number, and review the result before selecting **Konfirmasi check-in**. Searching by name alone does not record a visit.

## Check-in only or check-in and check-out

The owner selects the mode through **Pengaturan → Check-in**.

| Mode | Use |
| --- | --- |
| Check-in only | Record arrivals without recording departures. |
| Check-in and check-out | Record arrivals and departures; each member can have only one open visit. |

To record a departure, select **Keluar** before scanning or use **Catat keluar** on the relevant visit. Repeated entry scans do not automatically count as check-out.

When check-out is enabled, the **Di gym** tab helps you find visits that are still open, including those from previous days. Close all open visits before disabling check-out.

<AccordionGroup>
  <Accordion title="Access denied? Check the cause">
  - Check the member and branch status.
  - Make sure the membership is fully paid and still valid.
  - Check membership branch access.
  - In check-out mode, check whether a previous visit is still open.

  Gym check-in does not deduct personal training or class sessions. Record attendance for those services in their own modules.
  </Accordion>
  <Accordion title="Repeated scans or a lost connection">
  Repeated entry scans within a short period may return the visit already recorded. Check the result panel and history before trying again, particularly after a connection problem.

  For camera permissions, see [Help](/en/help).
  </Accordion>
</AccordionGroup>
